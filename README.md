# Flawless Themes for Zed

A collection of 19 hand-crafted themes for [Zed](https://zed.dev): 17 dark and 2 light.

## Themes

**Dark:** Graphite Dark, Graphite Pro, Graphite Code, Midnight Ocean, Ember Glow, Neon Synthwave, Forest Night, Moonlight Purple, Aurora Dusk, Carbon Bloom, Rose Nebula, Soot Ember Minimal, Arcade Carbon, Classic Terminal Ink, Mono Slate Pop, Retro Amber Console, Carbon Onyx

**Light:** Morning Mist, Arctic Frost

## Install

Open the extensions page (`zed: extensions`), search for **Flawless Themes**, and install it. Then pick a theme with `theme selector: toggle` (`Ctrl+K Ctrl+T`).

## Notes

These themes were ported from a VS Code theme pack. Zed highlights code with tree-sitter rather than TextMate grammars, so syntax colours are mapped onto Zed's capture names. Language-specific tweaks from the VS Code themes do not carry over; the palette does.
